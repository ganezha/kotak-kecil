# Code of Conduct

This is a short CoC for a small toolbox. Harassment is still not allowed just because the file is short.

## Our pledge

We pledge to make participation in **KOTAK kecil** a harassment-free experience for everyone, regardless of age, body, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

Kita berjanji ruang ini (issue, PR, commit, diskusi) aman dari pelecehan.

## Standards

**Do**

- Assume good intent. Correct the work, not the person.
- Keep tools small. Argue about the job, not the ego.
- Use inclusive language.
- Say when you don't know. That's the house style.

**Don't**

- Insults, personal attacks, trolling, sexualized language or imagery.
- Doxxing, stalking, or publishing private information.
- Opening a public issue that contains live secrets, tokens, keys, or `.env` values. Rotate first. See [SECURITY.md](SECURITY.md).
- Opening a PR that adds `.env`, keys, or tokens. It will be closed.

## Scope

This CoC applies in the GitHub repo, issues, pull requests, commit messages, and any official representation of the project.

## Enforcement

**Leaked credentials / tool vulns:** private [GitHub security advisory](https://github.com/ganezha/kotak-kecil/security/advisories/new).

**Conduct / harassment:** do **not** file a security advisory (advisory can become public after publish). Contact the owner [@ganezha](https://github.com/ganezha) privately, or use [GitHub report abuse](https://github.com/contact/report-abuse).

Maintainers will:

1. Acknowledge receipt when they can.
2. Investigate fairly.
3. Take action that matches the harm: warning, content removal, temporary ban, or permanent ban.

Maintainers who do not follow this CoC may lose their privileges.
